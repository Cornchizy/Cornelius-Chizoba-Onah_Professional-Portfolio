# Networking Fundamentals — Evidence

This folder contains screenshot evidence from my hands-on Networking Fundamentals labs completed using Kali Linux.

## Evidence Files

The screenshots document practical exercises involving:

- IP addressing and routing
- Network interfaces and MAC addresses
- Listening ports and services
- DNS
- Network configuration
- Network connectivity
- Subnetting and CIDR
- ARP and neighbor information
- Active network connections
- Traceroute
- Nmap
- Network troubleshooting

## Lab Environment

- Operating System: Kali Linux
- Virtualization: VirtualBox
- Network Mode: NAT
- IPv4 Address: 10.0.2.15/24

## Screenshot Naming Convention

Screenshots are numbered according to the order in which the practical exercises were completed.

Each screenshot is intended to provide visual evidence of the corresponding networking exercise.
