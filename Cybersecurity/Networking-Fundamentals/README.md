## Key Networking Concepts

### IP Address

An IP address identifies a device or network interface at the network layer and allows systems to communicate across networks.

### Ports

Ports identify specific network services or applications on a host.

Examples include:

- TCP 22 — SSH
- TCP 80 — HTTP
- TCP 443 — HTTPS
- UDP/TCP 53 — DNS

### DNS

DNS translates human-readable domain names into IP addresses so that systems can locate network services.

### DHCP

DHCP can automatically provide network configuration information such as an IP address, gateway, and DNS settings.

### TCP and UDP

TCP provides connection-oriented and reliable transport mechanisms, while UDP provides a lower-overhead transport mechanism without TCP's built-in delivery guarantees.

## Cybersecurity Relevance

Networking knowledge is essential for cybersecurity because security analysts need to understand how systems communicate.

Understanding IP addresses, ports, protocols, DNS, routing, and network connections helps with:

- Network troubleshooting
- Security monitoring
- Incident investigation
- Traffic analysis
- Threat detection
- Network reconnaissance
- Incident response
